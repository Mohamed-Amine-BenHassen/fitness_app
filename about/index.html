Your data

Everything stays
on this phone.

No account, no sync

Sets, meals and weigh-ins are saved in the browser on your phone. Nothing is sent anywhere.

One-file backup

Export everything as a single JSON file. Import it on any device to pick up where you left off.

History never rewritten

Updates upgrade old data and old backups automatically. A backup from a newer version is refused, not half-read.

Clearing the browser's site data deletes it all, so export a backup now and then.
